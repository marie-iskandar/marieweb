**Zieks** is a simple SHMUP inspired by the graphical style of 80s computer games, especially as on architectures with
[attribute clash](https://en.wikipedia.org/wiki/Attribute_clash), but there is no particular attempt to otherwise
adhere to the specifications of any actual device.

Most of the sprites were originally created with [Richard's Evolving Sprite Tool](https://www.allegro.cc/forums/thread/595177/0) and then edited to add animation etc.
Unfortunately, this must be stated in 2026: *This tool does not use gen AI. I remain opposed to gen AI.*

I originally wrote the bulk of this game in ~2007 in [Blitz3D](https://blitzresearch.itch.io/blitz3d),
which was already kind of a retro choice by the time. I happened to find it again while going through an old hard drive
and decided it might be fun to finally finish it and release it, especially following
[Mark Sibly's passing](https://github.com/blitz-research/libsgd/issues/2). BlitzBasic was formative to setting
me on my path. I originally planned to port the game by writing a Blitz3D
compiler (I started on it and might still do it next time I get a manic episode), but then decided to just port the
game itself to C++ instead so it would play nice on modern OSes and maybe WebAssembly.
